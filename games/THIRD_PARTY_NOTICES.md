# Tutaua Retro third-party components

Tutaua Retro contains no games, ROMs or console BIOS files.

The emulator frontend uses [LibretroDroid 0.13.2](https://github.com/Swordfish90/LibretroDroid/tree/0.13.2), licensed under GPL-3.0.

The ARMv7 build bundles these Libretro cores from the official Libretro Android buildbot (retrieved 2026-08-29):

| Core | Upstream source | License |
|---|---|---|
| FCEUmm | https://github.com/libretro/libretro-fceumm | GPL-2.0 |
| Snes9x | https://github.com/libretro/snes9x | Snes9x non-commercial license |
| Gambatte | https://github.com/libretro/gambatte-libretro | GPL-2.0 |
| mGBA | https://github.com/libretro/mgba | MPL-2.0 |
| Genesis Plus GX | https://github.com/libretro/Genesis-Plus-GX | Non-commercial license |
| Beetle PCE Fast | https://github.com/libretro/beetle-pce-fast-libretro | GPL-2.0 |

The complete license texts and corresponding source code must accompany any binary public release. Tutaua Retro is intended for personal, non-commercial use.
