Privacy Policy

Last updated: August 7, 2026

In short

Tutaua has no advertising or analytics and does not send your personal information to the developer. The app communicates directly with the Jellyfin server you choose.

About Tutaua

Tutaua is an independent client used to access a Jellyfin server configured and administered by the user or their server administrator. Tutaua does not provide, host, sell, or control media content.

Information processed by the app

To operate, Tutaua processes the server address, username, password during authentication, session token, a randomly generated installation identifier, library metadata, and playback information required to display content and synchronise progress.

This information is exchanged only with the server selected by the user. It is not sent to the Tutaua developer, advertising providers, or analytics services.

Local storage and security

The password is not stored after authentication. The session token is encrypted on the device using Android Keystore. The server address, username, and random installation identifier are stored locally so the app can operate. Session data is excluded from Android backup and device transfer.

Public servers should use HTTPS. HTTP is supported only for private local-network addresses, where transport security depends on the network and server administrator.

Retention and deletion

Local session information remains until the user signs out, clears Tutaua’s app data, or uninstalls the app. Information retained by a Jellyfin server is governed by that server administrator’s own configuration and privacy practices.

Children

Tutaua is not specifically directed to children and the developer does not knowingly collect children’s personal information. The server administrator is responsible for user profiles, parental controls, and available content.

Third-party services

Tutaua does not include advertising, analytics, or social-network SDKs. The app connects to the user-selected Jellyfin server, which is an independent service outside the developer’s control.

Changes to this policy

This policy may be updated when the app’s functionality or legal obligations change. The effective date appears at the top of this page.

Contact

For privacy questions, contact @yukista on GitHub. Please never send a server password or access token.
